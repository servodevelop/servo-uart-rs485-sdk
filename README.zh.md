# servo-uart-rs485-sdk

[English](README.md)

## Ecosystem

本仓库是 Star Arm 102 生态的 UART/RS485 舵机 SDK 组件，提供 Fashion Star 串行总线舵机控制示例和开发工具。

### 仓库说明

该仓库包括华馨京科技 uart&rs485 系列舵机的SDK例程。

通信协议以及更多资料请参考： [Fashion Star Wiki](https://wiki.fashionrobo.com/)
